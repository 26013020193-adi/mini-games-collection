# Mini Games Collection

A simple Python project containing three classic console games, all in one menu-driven program.

## Games Included
1. **Number Guessing Game**: guess the secret number between 1 and 100 in 7 attempts.
2. **Rock Paper Scissors**: play a best-of-5 match against the computer.
3. **Hangman**: guess the hidden word letter by letter before you run out of lives.

## Technologies Used
- Python 3
- `random` module (built-in, no installation needed)

## How to Run
1. Install Python 3 from [python.org](https://www.python.org/downloads/).
2. Download or clone this repository.
3. Open a terminal in the project folder and run:

```bash
python games.py
```

4. Choose a game from the menu by typing 1, 2, 3 (or 4 to exit).
